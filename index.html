Hey, I'm Rakeh.

I'm an AI Engineer at Kaba Construction, building MASON, a multi-agent renovation platform where LLM agents read site photos and write design direction, while every quantity, price, and crew schedule comes from deterministic code and Google OR-Tools.

Before that, as a Data Scientist at GA Telesis, I shipped a production probabilistic forecasting system for aviation spare-parts demand on AWS SageMaker and led an on-premise Document AI proof of concept.

I earned my PhD at Penn State, teaching machines to see the way expert inspectors do, using eye tracking, drones, and deep learning to assess buildings and bridges. That research thread is still very much alive.

If you're working on hard problems where models have to survive contact with the physical world, let's talk.

On-device AI agent

An autonomous agent that runs entirely on a consumer GPU: a local LLM in a LangGraph tool loop with about 50 tools, wake-word voice, hybrid document search (RAG), and scheduled briefings. No cloud AI, and every risky action waits for human approval.

MAISI · Sim2Real gaze distillation

My PhD, expanded: 30 virtual inspectors in Unity generate synthetic gaze, a Sim2Real gate checks it against real expert eye tracking, and a multimodal ViT teacher is distilled 7.7× into an RGB-only student for on-board drone inspection.
